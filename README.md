# Easyvocab

## Deploy to Render

1. Push this repository to GitHub.
2. In Render, choose **New > Blueprint**, connect the repository, and apply `render.yaml`.
3. Set the prompted environment variables:
   - `ADMIN_EMAIL`: email address that should receive the admin role when signing in with Google.
   - `GOOGLE_CLIENT_ID`: OAuth client ID configured for the deployed domain.
   - `FACEBOOK_APP_ID`: Facebook app ID (optional if Facebook login is not used).
   - `GMAIL_USER` and `GMAIL_APP_PASS`: Gmail account and app password for password-reset emails.
4. Wait for the deploy to finish. Render will show the public `https://...onrender.com` URL in the service dashboard.

`JWT_SECRET` is generated by the Render Blueprint. Do not replace it with a public/default value.

The app uses in-memory users and OTPs, so account data is not persistent and is lost whenever the service restarts. The built-in sample accounts only exist outside production. Add persistent storage before using this as a production account system.

For local development, set a private `JWT_SECRET` before running `npm start`.
